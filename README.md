📖 About This Repository

This repository contains my learning journey through 40 Days of JavaScript by Tapas Adhikary (Tapascript).

The goal of this challenge was not just to learn JavaScript syntax, but to develop a deeper understanding of how JavaScript works internally and apply the concepts through hands-on practice, challenges, debugging, and projects.

Over these 40 days, I covered JavaScript from fundamentals to advanced concepts, including DOM manipulation, asynchronous JavaScript, the Event Loop, OOP, prototypes, modules, performance optimization, and memory management.

40 Days → Consistent Practice → Stronger JavaScript Foundation 🚀
